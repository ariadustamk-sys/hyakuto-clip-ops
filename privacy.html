プライバシーポリシー

本ポリシーは、YouTube チャンネル「百灯一課 捜査記録」の運営補助ツール「hyakuto-clip-ops」（以下「本ツール」）における Google ユーザーデータの取り扱いを定めるものです。

1. 利用者

本ツールを利用するのはチャンネル管理者本人のみです。第三者のアカウントやデータにはアクセスしません。

2. 取得するデータ

YouTube Data API および YouTube Analytics API を通じて、管理者本人が所有するチャンネルの動画メタデータ（タイトル・説明文・タグ・サムネイル・公開設定）と視聴統計（再生数・視聴維持率・流入元など）を取得します。

3. 利用目的

取得したデータは、当該チャンネルの動画情報の更新と視聴分析にのみ使用します。

4. 保存と共有

OAuth の認証トークンは管理者のローカル端末にのみ保存します。取得したデータを外部サーバーへ送信したり、第三者に提供・販売したりすることはありません。広告や与信判断には使用しません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から取得した情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

6. データの削除

管理者は、Google アカウントの「アカウントにアクセスできるアプリ」から本ツールのアクセス権をいつでも取り消せます。取り消しに伴い、ローカルに保存したトークンも削除します。

7. お問い合わせ

本ポリシーに関するお問い合わせは、チャンネル概要欄に記載の連絡先までお願いします。

Privacy Policy (English)

"hyakuto-clip-ops" is a private tool used only by the owner of the YouTube channel "Hyakuto Ikka Sousa Kiroku". It accesses, via the YouTube Data API and YouTube Analytics API, only the video metadata and analytics of the channel owned by that user, solely to update video information and analyze viewership. OAuth tokens are stored only on the owner's local device. No data is transmitted to external servers, shared with, or sold to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account permissions page.
